# 💡 Códigos de Prática de Eletrônica Digital

Este repositório reúne implementações em **VHDL** desenvolvidas como parte das atividades práticas da disciplina de **Prática de Eletrônica Digital I** do curso de Engenharia de Software na **Universidade de Brasília (UnB)**.

Os códigos foram escritos e testados utilizando o software **Quartus II**, e cada projeto representa circuitos clássicos digitais utilizados em sistemas embarcados e lógicas programáveis.

---

## 📁 Projetos incluídos

- 🔢 **Decodificador de Prioridade**  
  Implementação de um circuito que detecta a entrada de maior prioridade entre várias linhas ativas.

- 🚗 **Alarme Automotivo**  
  Sistema simples de alarme digital com entradas representando sensores de portas, ignição e presença.

- ⏱️ **Cronômetro Digital**  
  Cronômetro de contagem crescente com controle de start, stop e reset, modelado com máquinas de estados.

- 🧮 **Unidade Lógica Aritmética (ULA)**  
  Implementação de uma ULA capaz de realizar operações como soma, subtração, AND, OR, entre outras, com controle via sinais de operação.

---

## 🛠️ Tecnologias utilizadas

- **VHDL (VHSIC Hardware Description Language)**
- **Quartus II** (desenvolvimento e simulação)
- **FPGA Altera/Intel** (para testes em hardware)

---

## 📚 Como utilizar

1. Abra o **Quartus II**.
2. Importe ou crie um novo projeto com base no arquivo `.vhd` correspondente.
3. Compile o projeto.
4. Utilize o **Simulation Waveform Editor** para simular os circuitos (ou teste em FPGA real, se disponível).
